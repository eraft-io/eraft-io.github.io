矩阵乘法：内积与外积视角

同一个矩阵乘法 C = A × B，从两种截然不同的视角理解

两种视角概述

内积视角： Cij = aiT bj  ← A 的第 i 行 · B 的第 j 列（点积）
外积视角： C = ∑k=1n ak bkT  ← A 各列与 B 各行的外积之和（秩1矩阵累加）

内积视角：逐个元素计算。C 的每个元素 = A 的一行与 B 的一列做点积，关注"一个结果元素怎么来"。
外积视角：逐层累加。C = 多个"秩1矩阵"之和，每个秩1矩阵由 A 的一列与 B 的一行做外积得到，关注"整个矩阵怎么拼出来"。

理解要点

内积视角回答"结果矩阵的一个元素如何计算"——适合理解单个数值的来源， 也是编程实现最自然的循环方式（三重循环 i → j → k）。

外积视角回答"结果矩阵的整体结构如何构成"——C 是 n 个秩1矩阵之和， 每个秩1矩阵由一个列向量和一个行向量外积而成。这在低秩近似、推荐系统（SVD分解）、 以及理解 Attention 机制中 QK^T 的分解时非常重要。
