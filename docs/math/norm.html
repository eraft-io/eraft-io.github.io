向量范数 · 几何直觉

范数衡量向量的“大小”——拖动向量，直观感受 L1 与 L2 的几何差异

定义

对向量 v = (x₁, x₂, …, xₙ)，不同的范数用不同方式度量它的大小：

L1 范数（曼哈顿）   ‖v‖₁ = |x₁| + |x₂| + ⋯ + |xₙ|
L2 范数（欧几里得）   ‖v‖₂ = √(x₁² + x₂² + ⋯ + xₙ²)
L∞ 范数（最大值）   ‖v‖∞ = max |xᵢ|
