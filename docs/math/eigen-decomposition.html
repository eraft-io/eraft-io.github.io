特征值分解的几何本质

A = QΛQᵀ ：旋转 → 缩放 → 转回，特征向量是"只缩放不旋转"的特殊方向

定义 Eigenvalue Decomposition

A = Q Λ QT
其中 Q 的列是特征向量（正交），Λ 是特征值对角阵

核心直觉：任何对称矩阵的作用都可以拆成三步—— ① 旋转到特征向量方向（Qᵀ）、 ② 沿轴缩放（Λ，特征值即缩放倍数）、 ③ 旋转回（Q）。
特征向量的几何意义：在矩阵变换下，方向不变（只被拉伸或压缩）的向量； 特征值就是沿该方向的拉伸/压缩比例。

计算实例 2×2 方阵 · 逐行动画

以 A = [[3, 1], [1, 3]] 为例（对称矩阵，保证特征向量正交）

1

求特征值 — det(A − λI) = 0

det(A − λI) = (3−λ)(3−λ) − 1×1
= λ² − 6λ + 8 = 0
→ 因式分解: (λ − 4)(λ − 2) = 0
→ λ₁ = 4，λ₂ = 2
2

求特征向量 — (A − λI)v = 0

λ₁ = 4： A − 4I = [[−1, 1], [1, −1]]
→ −v₁ + v₂ = 0 → v₁ = v₂
→ v₁ = [1, 1] / √2
λ₂ = 2： A − 2I = [[1, 1], [1, 1]]
→ v₁ + v₂ = 0 → v₁ = −v₂
→ v₂ = [1, −1] / √2
3

构造 Q 和 Λ

Q = [v₁ | v₂]
= [[1/√2, 1/√2], [1/√2, −1/√2]]
Λ = diag(λ₁, λ₂) = [[4, 0], [0, 2]]
4

验证 A = QΛQᵀ

Qᵀ = [[1/√2, 1/√2], [1/√2, −1/√2]] （Q = Qᵀ）
ΛQᵀ = [[4/√2, 4/√2], [2/√2, −2/√2]] = [[2√2, 2√2], [√2, −√2]]
Q(ΛQᵀ)[1,1] = (1/√2)(2√2) + (1/√2)(√2) = 2+1 = 3 ✓
Q(ΛQᵀ)[1,2] = (1/√2)(2√2) + (1/√2)(−√2) = 2−1 = 1 ✓
→ QΛQᵀ = [[3, 1], [1, 3]] = A ✓

几何本质 Why It Works

为什么特征向量不旋转？
因为特征向量的定义就是 Av = λv——矩阵 A 作用在 v 上，结果只是把 v 拉伸了 λ 倍， 方向完全不变（或反向，当 λ<0）。这是"特征"二字的本质含义。

三步分解的直观含义：
  ① Qᵀ（旋转）：把空间转到"特征向量坐标系"，让 v₁ 对齐 x 轴、v₂ 对齐 y 轴
  ② Λ（缩放）：在特征坐标系中，x 方向拉伸 λ₁ 倍、y 方向拉伸 λ₂ 倍
  ③ Q（转回）：把空间转回原来的朝向

单位圆经过变换后变成椭圆，而特征向量恰好是椭圆的主轴方向， 特征值就是主轴的半轴长度。这就是特征值分解的几何全貌。
